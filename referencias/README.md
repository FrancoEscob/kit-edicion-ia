# Tus referencias

Guardá acá videos que te gusten, **una carpeta por tipo de estilo**:

```
referencias/
  talking-head-minimal/
    links.txt      ← un link por renglón (YouTube, Reels, TikTok, X…)
    ref-01.mp4     ← o los archivos directo
    notas.md       ← opcional: qué te gusta y qué no
  podcast-premium/
  reels-con-ui/
```

Cuando tengas 5 o más de un tipo, pedile a Claude: **"destilá mis referencias de <tipo> en un estilo"**. Las mide (cortes, subtítulos, tipografías, colores, composición, movimiento y sonido), arma un estilo propio en `estilos/propios/` y lo prueba con un video tuyo.

También podés pedir con un solo video:
- "¿Cómo está hecho este video?" → te lo desarma.
- "Rehacé este video con mi contenido" → lo reconstruye como proyecto editable.

Lo que guardes acá es tuyo y no se sube a ningún lado.
